Knowledge / Wiki Layer

Video ini mengajarkan bahwa backtest tradisional (full-history) selalu berbohong karena fenomena curve fitting — bot hanya menghafal data masa lalu. Solusinya adalah walk-forward analysis: melatih pada window terbatas, mengunci parameter, lalu menguji pada data blind yang belum pernah dilihat. Hanya out-of-sample returns yang digabungkan sebagai ukuran performa nyata. Engine dibangun dengan Claude Code (VS Code plugin) menghasilkan Streamlit app tanpa menulis Python sendiri. ---

Walk-forward wiki topics

  • Walk-Forward Analysis — Engine yang melatih pada window terbatas lalu blind-test di window berikutnya secara berulang.
  • Curve Fitting — Jebakan backtest tradisional: bot menghafal data historis, bukan menemukan edge nyata.
  • In-Sample vs OOS — In-sample = ilusi; OOS (stitched blind folds) = ukuran performa nyata.
  • Return Degradation — Persentase return yang terbukti palsu setelah walk-forward.
  • Transaction Costs — 0.1% exchange fee + slippage wajib dimasukkan agar tidak overestimate.
  • Look-Ahead Bias — filtfilt menggunakan data masa depan; lfilter wajib dipakai.
