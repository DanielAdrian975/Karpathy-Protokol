Karpathy Workspace: Audit Isi, Protokol, dan Peluang Pengembangan

Laporan HTML bergaya Wikipedia berdasarkan audit folder Karpathy, dokumen proses, status Git/bd, dan kandidat pengembangan protokol/skills. Dibuat sebagai artifact statis yang dapat dibuka langsung di browser.

Karpathy adalah workspace protokol dan knowledge orchestration untuk trading research, bukan satu repository aplikasi tunggal. Fungsi utamanya adalah control tower untuk routing task, audit evidence, wiki memory, AutoResearch, C4-ET, Boris Workflow, dan project closure berbasis Git/bd.

Kesimpulan eksekutif: sistem protokol sudah matang dan dapat dipakai. Bottleneck utama adalah pemilihan authoritative implementation subproject, canonical test command, rekonsiliasi legacy wiki, dan staging source corpus yang masih harus dikendalikan secara curated.

Kandidat implementasi

hermes-things/ paling operasional karena memiliki pyproject.toml, requirements.txt, modul Python, dan test files. Kandidat test command: python -m pytest tests/ -v setelah dependency audit ringan.

Temuan audit

  1. Protokol matang. Enam protokol utama sudah terdokumentasi dan pernah divalidasi secara lokal.
  2. Authority implementation belum diputuskan. Ini blocker utama untuk implementation work.
  3. Legacy wiki belum reconciled. Root wiki sudah aktif, tetapi sumber lama belum termigrasi dengan SourceID.
  4. Source corpus berisiko. Ada credential-like path, archive, DB lokal, nested git, dan generated folders.
  5. Stale process note terdeteksi. QUALITY_GATES.md masih perlu sinkronisasi kecil terkait Gate 6 bila belum dipatch.

Guardrails
