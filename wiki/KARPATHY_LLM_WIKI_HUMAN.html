1. Project Snapshot

Sistem utama

Forex Trading Strategy Development System: video edukasi → ekstraksi knowledge → strategi terstruktur → backtesting → live trading MT5.

Architecture style

Multi-agent, Python 3.8+, OpenCV, Whisper AI, Pydantic, Streamlit, MT5 integration, knowledge graph, Zettelkasten.

Wiki discipline

Index-first, ringkasan 3-5 kalimat, frontmatter, source registry, unresolved questions, query surfaces.

Status

Root wiki aktif. Legacy LLM Wiki Karpathy/ belum sepenuhnya dimigrasikan ke normalized root wiki/.

2. Master Workflow

1. Educational Video
Input berupa video edukasi trading, audio, frames, dan material pendukung.
2. Video Processing Pipeline
OpenCV mengekstrak frames; Whisper mengekstrak transcript; visual/audio knowledge digabung.
3. Strategy Generator
Knowledge dikonversi menjadi model strategi berbasis Pydantic dan library JSON.
4. Backtesting System
Strategi diuji terhadap historical CSV MT5 multi-pair/multi-timeframe dengan agent orchestration.
5. Live Trading System
Strategi tervalidasi masuk dashboard Streamlit dan eksekusi/monitoring via MetaTrader 5.

7. Rules Prompting LLM Wiki

RuleInstruksi promptStop condition
Index firstBaca index, registry, unresolved sebelum file detail.Jika index tidak memuat topik, jangan tebak.
Raw immutableJangan ubah raw source; buat normalized wiki page.Jika perlu edit raw, minta approval eksplisit.
SourceID/provenanceSetiap ringkasan punya source_path/source_id bila ada.Jika source tidak jelas, mark unresolved.
3-5 sentencesRingkas tiap entity/topic dalam 3-5 kalimat.Jika panjang, pecah ke claims/links.
Claim statusLabel klaim: supported, partial, unsupported, unresolved.Klaim performa tanpa backtest/source = unresolved.

8. Roadmap Wiki

Phase A — Stabilize
Gunakan HTML portal ini sebagai navigasi manusia; jangan stage broad corpus.
Phase B — Reconcile
Migrasikan legacy source registry ke wiki/sources/ dengan SourceID/status.
Phase C — Normalize
Buat wiki/entities/, wiki/topics/, wiki/claims/, wiki/query-surfaces/.
Phase D — Verify
Jalankan MAS Evidence-First untuk klaim performa, risk, live trading, automation.
Phase E — Operationalize
Hubungkan prompt pack PMO dengan wiki retrieval: intake → source lookup → evidence packet → closure log.

9. Unresolved / Caution

  • Legacy wiki belum sepenuhnya dimigrasikan ke root wiki/.
  • Authoritative implementation subproject belum dipilih.
  • Canonical root test command belum ditetapkan.
  • Credential-like files di Bahan/.streamlit/ tetap NO-GO tanpa izin eksplisit.
  • Klaim performa trading harus diverifikasi dengan primary evidence/backtest.
