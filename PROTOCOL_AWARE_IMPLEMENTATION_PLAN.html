Architecture: Always-Aware Execution Loop

1. IntakeUser goal, expected output, constraints, risk, data source, write scope.
2. Protocol RouterSelect primary mode + support protocols via trigger matrix.
3. Plan PacketBoris plan: goal, files, gates, evidence standard, issue ID.
4. ExecuteScoped changes only. No raw-source mutation. No secrets.
5. VerifyTests, docs checks, citations, evidence packets, or C4-ET gates.
6. MemoryWiki/index/log, decision log, risk register, progress update.
7. Releasebd close/sync, commit, push, handoff with residual risk.

Design Principle

Sistem ini bukan menambahkan ritual. Sistem ini memaksa agent memilih protokol yang tepat sebelum eksekusi, lalu membuktikan hasil lewat artifact yang bisa diaudit.

Acceptance Criteria

  • Setiap task punya Protocol Precheck.
  • Setiap mode punya artifact wajib.
  • Research claims tidak boleh tanpa MAS evidence.
  • Capacity/team decisions tidak boleh tanpa C4-ET gate.
  • Durable knowledge selalu masuk LLM Wiki layer.
  • Implementation selalu pakai Boris Workflow: plan → execute → verify.
  • Session close selalu pakai project-management closure: bd, git, progress, handoff.

def route_task(user_request):
    protocols = []
    primary_mode = classify_primary_mode(user_request)

    if has_factual_or_research_claims(user_request):
        protocols += ["MAS Evidence-First", "AutoResearch"]
    if has_capacity_or_bottleneck_terms(user_request):
        protocols += ["C4-ET Gate"]
    if creates_durable_knowledge(user_request):
        protocols += ["LLM Wiki Karpathy"]
    if changes_code_docs_or_process(user_request):
        protocols += ["Boris Workflow"]
    if workflow_is_repeated_or_tool_specific(user_request):
        protocols += ["Skills"]
    protocols += ["Project Management"]

    return ProtocolPacket(primary_mode, unique(protocols), required_artifacts(primary_mode, protocols))

## Mandatory Protocol Precheck

Before any substantial task, run the protocol router:
1. Select exactly one primary mode.
2. Activate all supporting protocols required by triggers.
3. Produce a short precheck packet.
4. Stop if evidence, tests, secrets, or git/bd safety are unresolved.

Use docs/process/PROTOCOL_AWARE_EXECUTION_SYSTEM.md as source of truth.
## Gate -1 - Protocol Awareness

- User goal classified.
- Primary mode selected.
- Supporting protocols selected.
- Required artifacts listed.
- Relevant skills loaded.
- Evidence/test/git/bd stop conditions checked.
- Proceed / Stop decision recorded.
